# Course map — A1 → B1

58 lessons in 16 units. ✔ = already built (existing lesson id kept so saved progress survives), ★ = to write.

Every lesson follows the same path:

**Watch** (board-lecture video) → **Theory** → **Examples** (listen & repeat) → **Practice** (recognise, then produce) → **Game** → items join the **Review** queue.

Each unit ends with a checkpoint test; each level ends with a level exam.
